# nairr-eager

Website for the **NAIRR Workshop Series: Cybersecurity, Edge AI & Autonomous Systems**, a NAIRR EAGER project
by Oakland University and Worcester Polytechnic Institute.

**Live site:** https://ou-care-ai.github.io/nairr-eager/

- `index.html`: the whole site (static HTML, no build step)
- `assets/site.css`: shared house style, also used by the org site
- `assets/img/`: workshop thumbnails (slides from each workshop's public repo) and `ph-*.svg` placeholders

Workshop materials stay in their own repositories; this site links to them. Images named `ph-*.svg` are
placeholders waiting for real content.
